# Research methods and experiment coverage

Audit date: 1 October 2026. This file separates **Swift measurements** from results published on other corpora. Published scores are context, never entries in Swift's frozen-split leaderboard. The master Swift results are in [`ml/reports/RESULTS.md`](../../ml/reports/RESULTS.md); its generated tables and `ml/reports/runs/*.json` are the evidence for classifier runs. `docs/publications/archive/icatc/sections/04_classifiers.tex` supplies additional presentation tables, but does not create new runs.

## What “per language” means

`multi`: one fit on all five language tracks, then a pooled evaluation and five separate language scores. `mono`: five independent fits, each trained and evaluated on one track. A five-column test table establishes **per-language evaluation**, not `mono` training. Dev selects models; the frozen test set is reserved for finalists.

| Family and task | Pooled fit, dev by language | Pooled fit, test by language | Independent mono fits |
|---|---|---|---|
| Encoders, intent | LaBSE, XLM-R base, mmBERT, MuRIL, IndicBERT, TwHIN-BERT: all five dev cells | LaBSE, XLM-R base, mmBERT, MuRIL: all five; IndicBERT and TwHIN-BERT: no test | None recorded on the frozen split |
| Encoders, sentiment v8 | Same six: all five dev cells | LaBSE, XLM-R base, mmBERT, MuRIL: all five; IndicBERT and TwHIN-BERT: no test | None on v8. LaBSE, XLM-R base, TwHIN-BERT and LaBSE-LoRA have five **v5** mono dev runs each; the new LaBSE seed-43 Kaggle results also used v5 labels, despite an initial incorrect v8 stamp |
| Encoders, priority | Same six: all five dev cells | MuRIL: all five run JSONs. LaBSE has six new scores verified from saved test posteriors; XLM-R has separate checkpoint re-scores in `RESULTS.md` §2. Classical pooled, mono and English-transfer dev/test cells are now complete on the frozen split; they do not fill the neural mono gap.

## Interpretation rules

- Current sentiment comparisons require **v8** labels and Negative-F1. The v5 neural mono runs cannot prove whether specialists beat the v8 pooled champion.
- `docs/publications/archive/icatc/sections/04_classifiers.tex` repeats some results with selected language rows. The run JSONs and generated tables decide provenance. One discrepancy was corrected on 1 October: LaBSE sentiment seed 42 pooled **0.7138** must be paired with seed 42 language scores **0.8032 / 0.7234 / 0.6757 / 0.7606 / 0.5948**, not seed 43 language scores.
- Published paper metrics refer to their own labels, splits and domains. They are kept in this separate file rather than inserted into Swift's model leaderboard.
