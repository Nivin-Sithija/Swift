## A font trap worth knowing about

The first build of this paper typeset in **Latin Modern, not Times**, and
reported it only as 77 "LaTeX Font Warning: Font shape `TU/ptm/m/n' undefined"
lines that look like noise.

`IEEEtran` requests Times as `ptm`. Under pdfLaTeX that resolves from the
standard PostScript fonts. Under a Unicode engine (XeTeX or LuaTeX, which is
what Tectonic runs) the request silently falls back to Latin Modern and the
document is no longer in an IEEE-conformant typeface. Nothing fails; the PDF
just comes out in the wrong font.

`main.tex` now loads `newtxtext,newtxmath` under `[T1]{fontenc}` explicitly, so
the document typesets in Times under every engine. Do not remove those lines.
Verify with the font check below rather than by eye, since Latin Modern and
Times are easy to confuse at a glance in a two-column layout.

## How to re-verify

```bash
cd paper/drafts/latex
sed -i '' 's/^\\draftmodetrue/\\draftmodefalse/' main.tex
tectonic -X compile main.tex --outdir /tmp/chk
sed -i '' 's/^\\draftmodefalse/\\draftmodetrue/' main.tex

python3 - <<'PY'
from pypdf import PdfReader
r = PdfReader('/tmp/chk/main.pdf'); b = r.pages[0].mediabox
print('pages:', len(r.pages), '(limit 6)')
print('size :', round(float(b.width),2), 'x', round(float(b.height),2), '(A4 = 595.28 x 841.89)')
fonts = set()
for pg in r.pages:
    f = pg.get('/Resources', {}).get('/Font', {})
    try: f = f.get_object()
    except Exception: continue
    for k in f:
        try: fonts.add(str(f[k].get_object().get('/BaseFont')))
        except Exception: pass
print('Times?', any('Termes' in x or 'Times' in x or 'NimbusRom' in x for x in fonts))
PY

# double-blind
pdftotext /tmp/chk/main.pdf - | grep -ciE 'seneviratne|sutharsan|shaheed|swift-support|huggingface|github|@'
```

The double-blind command must print `0`.

## Before uploading to CMT

1. Set `\draftmodefalse` and confirm 6 pages.
2. Confirm `\blindtrue`.
3. Run the double-blind grep above and confirm it prints 0.
4. Run a similarity check. The call desk-rejects above 30\%. Your own public
   dataset and model cards describe this corpus in overlapping language; the
   manuscript prose is newly written, but the corpus description is the part
   most likely to match, so check it before submitting rather than after.
